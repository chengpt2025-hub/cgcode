## 优点

- **模型自由**：默认接入商汤日日新，也能用 DeepSeek、通义千问、Kimi 及任何兼容 OpenAI 格式的接口和中转站；终端版内置 Chat 接口适配，只支持 Chat 接口的国产模型也能完整驱动；桌面版可在界面里随时切换模型。
- **全中文**：界面、命令说明、欢迎页、提示和预装技能全部是简体中文，按中文说法触发。
- **零门槛**：首次启动有中文设置向导并自动测试连通；桌面版只需填一个 API Key；不需要任何海外账号。
- **隐私优先**：Key 只存在本机，对话只发给你自己配置的模型；使用数据上报、会话遥测默认全部关闭；自动更新只连 cgcode 自己的地址。
- **稳定**：遇到限流自动重试，可配置备用接口自动切换。
- **技能丰富**：终端版预装 6 个、桌面版预装 38 个技能，内置中文技能市场，可一句话搜索并在安全检查后一键安装；不含“破甲/越狱”类技能。
- **全能**（桌面版）：聊天、联网搜索、Word/Excel/PPT、图片、编程、多智能体协作、定时任务、电脑操控、全网阅读、长期记忆、本地离线模型、配音、创作者工作室。
- **安全**：窗口全部沙箱隔离；随客户端发布的有漏洞依赖已升到修复版本；需要联网安装组件的技能都固定版本，并且装之前先征得同意。
- **好看**：iOS 风格界面（iOS 蓝、大圆角），终端版 7 套主题；10 秒开机动画配音乐。

## 缺点

- 只支持 Windows。
- 还没在真实 Windows 电脑上完成验收。
- 安装包未签名，首次运行会出现 Windows 提示，需要点“仍要运行”。
- 桌面版安装包约 340 MB，目前要登录 GitHub 从 Actions 页面下载。
- 自动更新要在仓库开启 GitHub Pages 并发布更新文件后才生效。
- 部分功能第一次使用要额外安装组件（Node.js、uv、Ollama 等）；配音需要 Python 和较好的 NVIDIA 显卡。
- 需要登录的社交平台阅读默认关闭，开启有封号风险。
- 毛玻璃等完整 iOS 效果和手机遥控暂未提供。
- 模型服务（如日日新）有频率限制，高峰期需要等待自动重试。
