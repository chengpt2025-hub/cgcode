# 创作者工作室

## 流程
1. **定方向**：问清平台(抖音、B站、视频号等)、时长、题材、目标观众、风格(搞笑、热血、温情)、角色数量。
2. **剧本**：写成表格——场景 / 角色 / 台词 / 动作或画面 / 时长；台词口语化，节奏紧凑，开头 3 秒要有钩子。
3. **分镜**：为每个场景写画面描述，可用于手绘、动画或 AI 生图；需要时调用生图或海报类技能。
4. **角色声音**：为每个角色定音色(性别、年龄、性格、方言)；用“配音与朗读”技能逐句生成，文件按 `场景号_角色_序号_AI合成.wav` 命名。
5. **字幕**：根据台词和每段音频时长生成 SRT 字幕文件。
6. **交付清单**：剧本表、分镜、音频文件夹、字幕文件，并说明在剪映等软件里如何对齐。

## 规则
- 声音克隆遵守“配音与朗读”技能的授权规则。
- 不使用他人受版权保护的角色、音乐和画面，除非用户确认已获授权；游戏题材二创需遵守平台和游戏厂商的二创规范。
- 平台发布时提醒标注“AI 生成内容”。
