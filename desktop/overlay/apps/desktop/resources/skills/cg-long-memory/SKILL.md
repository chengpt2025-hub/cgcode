# 长期记忆

## 文件
- 位置：用户主目录下 `.cgcode/MEMORY.md`(Windows 为 `%USERPROFILE%\.cgcode\MEMORY.md`)，不存在就创建。
- 只保存在本机，不上传。

## 何时读取
- 开始一个新任务或新对话时，如果文件存在，先读一遍，按其中的偏好做事。
- 用户问“你还记得……吗”时读取并回答；也可以配合“历史会话搜索”查以前的对话。

## 何时写入
- 只在用户明确要求记住，或用户表达了长期有效的偏好时写入(例如“以后回复都简短一点”“我公司叫……”)。
- 写入前用一句话告诉用户你要记什么。
- 每条一行，带日期，按主题分组：`## 偏好`、`## 关于我`、`## 项目与约定`。
- 新内容与旧内容冲突时更新旧条目，不重复记录。

## 不要记
- 密码、验证码、银行卡号、身份证号、API Key 等敏感信息，即使用户要求也要提醒风险并拒绝保存。

## 忘记
- 用户说“忘掉……”时删除对应条目，并确认已删除。
