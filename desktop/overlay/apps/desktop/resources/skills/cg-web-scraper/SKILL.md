# 网页数据抓取

1. 先确认目标网址、要哪些字段、要抓多少页。
2. 先用 Python requests + BeautifulSoup 抓静态页面；页面靠 JavaScript 加载或需要点击翻页时，改用浏览器自动化(agent-browser 技能或 Playwright)。
3. 遵守规则：查看 robots.txt；控制频率(每次请求间隔 1-3 秒)；不抓需要登录才能看的他人隐私数据；不绕过验证码和付费墙；遵守网站服务条款和中国法律。
4. 清洗去重后保存为 Excel(xlsx)，第一行是中文表头，并告诉用户总条数和样例。
5. 网站结构变化或被拦截时，说明原因并给出替代办法。
