# 配音与朗读(VoxCPM2)

## 首次使用：安装(需用户同意)
1. 说明：需要 Python 3.10 以上，最好有 NVIDIA 显卡(约 8GB 显存以上)，模型约几 GB，首次下载较慢。
2. 没有 uv 时先安装(见“全网阅读”技能里的 uv 安装命令)。
3. 创建独立环境并安装：`uv venv %USERPROFILE%\.cgcode\voice && %USERPROFILE%\.cgcode\voice\Scripts\activate && uv pip install voxcpm`
4. 以 VoxCPM 官方 README(github.com/OpenBMB/VoxCPM)中的最新示例为准生成语音；国内网络可从 ModelScope 下载模型。

## 朗读 / 配音
- 先确认：要读的文字、语言或方言、语气(平静、激动、搞笑等)、语速、输出格式(默认 wav)。
- 长文本按句分段生成后再拼接，避免中途失败。
- 输出保存到用户指定目录，默认 `文档\cgcode配音\`。

## 声音克隆(必须遵守)
- 克隆前必须让用户确认：参考声音是**用户本人**，或已获得声音主人的**明确授权**。不能确认就拒绝。
- 不克隆公众人物、明星、政要的声音；不生成冒充他人、诈骗、诽谤或色情内容。
- 生成的文件名一律带“AI合成”字样，例如 `角色A_AI合成_001.wav`，并提醒用户发布时标注“AI 生成”。

## 没有显卡时
- 说明 CPU 也能运行但很慢；可建议使用短句或改用云端语音服务。
