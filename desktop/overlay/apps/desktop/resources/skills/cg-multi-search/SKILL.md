# 多引擎搜索

1. 把问题改写成适合搜索的关键词(中文为主，必要时加英文)。
2. 依次用多个来源搜索：内置联网搜索工具；必应 https://cn.bing.com/search?q=；百度 https://www.baidu.com/s?wd=；搜狗 https://www.sogou.com/web?query=；需要时打开网页阅读正文。
3. 汇总：去掉重复和广告，按可信度排序(官方网站、权威媒体优先)。
4. 输出：结论要点 + 每条附来源链接和发布日期；信息相互矛盾时标出来。
