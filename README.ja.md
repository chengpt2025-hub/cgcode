## 長所

- **モデルを自由に選べる**：既定は SenseNova（日日新）。DeepSeek、通義千問、Kimi、OpenAI 互換の任意の API や中継サービスも使えます。ターミナル版は Chat API 適配層を内蔵し、Chat API のみのモデルでもエージェントを完全に動かせます。デスクトップ版は画面上でいつでもモデルを切り替えられます。
- **完全中国語対応**：画面、コマンド説明、ようこそページ、ヒント、同梱スキルはすべて簡体字中国語です。
- **導入が簡単**：初回起動時に中国語の設定ウィザードが接続を自動テスト。デスクトップ版は API キーを 1 つ入力するだけ。海外アカウントは不要です。
- **プライバシー重視**：キーは手元の PC にのみ保存し、会話は自分で設定したモデルにだけ送信。利用データ送信とテレメトリは既定でオフ。自動更新は cgcode 独自のアドレスにのみ接続します。
- **安定**：レート制限時に自動再試行し、予備の接続先へ自動切り替えできます。
- **豊富なスキル**：ターミナル版 6 個、デスクトップ版 38 個を同梱。中国語のスキルマーケットで検索し、安全確認後にワンクリック導入できます。脱獄系スキルは含みません。
- **オールインワン**（デスクトップ版）：チャット、ウェブ検索、Word/Excel/PPT、画像、プログラミング、マルチエージェント協調、定期タスク、PC 操作、ウェブ閲読、長期記憶、ローカルのオフラインモデル、音声合成、クリエイタースタジオ。
- **安全**：全ウィンドウをサンドボックスで分離。クライアントに同梱される脆弱な依存関係は修正版に更新済み。ネットから部品を導入するスキルはバージョンを固定し、導入前に必ず同意を得ます。
- **美しい**：iOS 風 UI（iOS ブルー、大きな角丸）、ターミナル版テーマ 7 種、音楽付き 10 秒の起動アニメーション。

## 短所

- Windows 専用です。
- 実機の Windows での検収はまだ済んでいません。
- インストーラーは未署名のため、初回実行時に Windows の警告が出ます。「実行」を選んでください。
- デスクトップ版のインストーラーは約 340 MB で、現在は GitHub にログインして Actions ページからダウンロードする必要があります。
- 自動更新は、リポジトリで GitHub Pages を有効にし更新ファイルを公開した後に有効になります。
- 一部の機能は初回利用時に追加部品（Node.js、uv、Ollama など）の導入が必要。音声合成には Python と高性能な NVIDIA GPU が必要です。
- ログインが必要な SNS の閲読は既定でオフで、有効にするとアカウント停止のリスクがあります。
- すりガラスなどの完全な iOS 効果とスマホ遠隔操作はまだ提供していません。
- SenseNova などのモデルサービスにはレート制限があり、混雑時は自動再試行を待つ必要があります。
