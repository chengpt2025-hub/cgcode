## 優點

- **模型自由**：預設接入商湯日日新，也能用 DeepSeek、通義千問、Kimi 及任何相容 OpenAI 格式的介面和中轉站；終端版內建 Chat 介面適配，只支援 Chat 介面的國產模型也能完整驅動；桌面版可在介面中隨時切換模型。
- **全中文**：介面、命令說明、歡迎頁、提示和預裝技能全部是中文，按中文說法觸發。
- **零門檻**：首次啟動有中文設定精靈並自動測試連通；桌面版只需填一個 API Key；不需要任何海外帳號。
- **隱私優先**：Key 只存在本機，對話只發給你自己設定的模型；使用資料上報、會話遙測預設全部關閉；自動更新只連 cgcode 自己的位址。
- **穩定**：遇到限流自動重試，可設定備用介面自動切換。
- **技能豐富**：終端版預裝 6 個、桌面版預裝 38 個技能，內建中文技能市場，可一句話搜尋並在安全檢查後一鍵安裝；不含「破甲/越獄」類技能。
- **全能**（桌面版）：聊天、聯網搜尋、Word/Excel/PPT、圖片、程式設計、多智能體協作、定時任務、電腦操控、全網閱讀、長期記憶、本機離線模型、配音、創作者工作室。
- **安全**：視窗全部沙箱隔離；隨用戶端發佈的有漏洞依賴已升到修復版本；需要聯網安裝元件的技能都固定版本，並且安裝前先徵得同意。
- **好看**：iOS 風格介面（iOS 藍、大圓角），終端版 7 套主題；10 秒開機動畫配音樂。

## 缺點

- 只支援 Windows。
- 尚未在真實 Windows 電腦上完成驗收。
- 安裝包未簽名，首次執行會出現 Windows 提示，需要點「仍要執行」。
- 桌面版安裝包約 340 MB，目前要登入 GitHub 從 Actions 頁面下載。
- 自動更新要在倉庫開啟 GitHub Pages 並發佈更新檔後才生效。
- 部分功能第一次使用要額外安裝元件（Node.js、uv、Ollama 等）；配音需要 Python 和較好的 NVIDIA 顯示卡。
- 需要登入的社群平台閱讀預設關閉，開啟有封號風險。
- 毛玻璃等完整 iOS 效果和手機遙控暫未提供。
- 模型服務（如日日新）有頻率限制，尖峰時段需要等待自動重試。
